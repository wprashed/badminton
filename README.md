# Badminton Cup — Pro Tournament Suite & Admin Platform

A commercial, BWF-compliant tournament management SaaS web application built with modern vanilla web technologies, SupportHub slate aesthetics, and PWA offline capabilities.

## Features
- **Official BWF Rally Scoring**: Full support for 21-point rally scoring laws, deuce, 30-point sudden death, intervals, and change of ends.
- **Dynamic Court Visualizer**: Real-time service/receiver diagonal highlighting for singles and doubles.
- **Tournament Stage Engine**: Round-robin group stage with official BWF tiebreak hierarchy (Head-to-Head priority), playoff bracket generator, and 3rd place playoff.
- **Match Scheduler & Arena Stadium TV**: Multi-court display with full-screen TV view and live court dispatching.
- **Signable BWF Scorecards**: Official Form 4 match scorecards with touch/stylus signature pads for umpires and team captains.
- **Head-to-Head Analytics & Elo**: Performance comparisons with standard Elo probability calculations.
- **PWA & Offline First**: Service worker caching and offline resilience for venues with spotty connectivity.
